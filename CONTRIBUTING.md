# Contributing

Thank you for helping with Mneme.

- **Build and check** with [mise](https://mise.jdx.dev): `mise install`, then `mise run gate`. It formats, lints, tests and audits, as CI does, and must pass before a change is merged.
- **Commits** have one imperative sentence as their subject, with no prefix, such as `Refuse a token over plain HTTP`. The body says why.
- **Pull requests** go to `main`. Every push to `main` deploys, so keep it green.
- **Choices** that the code does not explain go in [docs/decisions.md](docs/decisions.md).

[docs/development.md](docs/development.md) has the rest: the tests, the image check, the screenshots and releases.
